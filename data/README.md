# InPage data file (not in this repo)

The InPage → Unicode converter needs `observations.json` in this folder:
the font-encoding table from the Koshur Editor app's assets
(`assets/flutter_assets/assets/inpage_pdf/observations.json`).

It comes from inside that app, so it is deliberately NOT committed here.
Drop your own copy into this folder to enable the converter locally;
without it the tab shows a clean "not installed" message.
